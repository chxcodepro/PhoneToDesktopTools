# P2D 安装说明

用手机通过数据线控制电脑。电脑端支持 Windows 10 / 11、Windows 7 SP1、银河麒麟桌面操作系统 V10（SP1）、macOS 10.13 及以上（Intel 和 Apple 芯片）。手机端支持 Android 和 iPhone。电脑不需要联网。

## 交付文件

| 文件 | 用途 |
|---|---|
| `P2D-<版本>-android.apk` | 手机端 App（一般不用手动装：手机插上电脑时，电脑端会自动安装） |
| `P2D-<版本>-win-x64-setup.exe` | Windows 10 / 11 / 7 的 64 位电脑（安装程序） |
| `P2D-<版本>-win-ia32-setup.exe` | 32 位 Windows（少见，64 位系统用上面那个） |
| `P2D-<版本>-linux-arm64.deb` | 银河麒麟 arm64（飞腾、鲲鹏、海思麒麟） |
| `P2D-<版本>-linux-amd64.deb` | 银河麒麟 x86_64（兆芯、海光、Intel） |
| `P2D-<版本>-linux-loongarch64.deb` | 银河麒麟龙芯 3A5000 / 3A6000 |
| `P2D-<版本>-mac-arm64.dmg` | Mac（Apple 芯片：M1 及以后） |
| `P2D-<版本>-mac-x64.dmg` | Mac（Intel 芯片） |
| `P2D-<版本>-ios-unsigned.ipa` | iPhone 手机端（未签名，要自己签名安装，见「iPhone」一节） |

不确定麒麟电脑是哪种 CPU：打开终端运行 `uname -m`，`aarch64` 用 arm64 版，`x86_64` 用 amd64 版，`loongarch64` 用龙芯版。

## 一、手机准备（每台手机做一次）

1. 打开「开发者选项」：设置 → 关于手机 → 连续点「版本号」7 次。
2. 设置 → 系统（或「其他设置」）→ 开发者选项，打开「USB 调试」。
   - 小米手机还要打开「USB 安装」和「USB 调试（安全设置）」。
   - OPPO / 一加 / vivo 如有「禁止权限监控」「USB 安装需验证」之类的选项，按提示允许。
3. 第一次插上电脑时，手机会弹出「允许 USB 调试吗？」，勾选「一律允许这台计算机」，点「允许」。

iPhone 不用开任何调试选项，见下面「iPhone」一节。

## 二、Windows 10 / 7

1. 双击 `P2D-<版本>-win-x64-setup.exe` 安装（可以从 U 盘直接运行）。默认装到当前用户的目录，不需要管理员权限；也可以选「为所有用户安装」或换安装位置。装完自动打开，桌面和开始菜单都有「P2D」。
   - 以前用过便携版（`-portable.exe`）的：先在托盘图标上右键「退出」，装好安装版后删掉旧的 exe；开机自启会自动改到安装版。
   - 卸载：「设置 → 应用」或控制面板里卸载 P2D，会一并去掉开机自启；配对记录和设置保留在 `%APPDATA%\p2d`，不需要可以手动删掉。
2. 用数据线连接手机。电脑端会自动给手机安装 App 并连接，窗口显示「已连接 · USB」即可在手机上操作电脑。
3. 如果窗口里「Android 驱动」显示「缺少驱动」（Win7 常见）：点「安装驱动」→ 弹出的管理员确认点「是」→ 提示「无法验证此驱动程序软件的发布者」时点「始终安装此驱动程序软件」。装好后自动连接。
4. Win7 需要 SP1，不需要装其他系统补丁。

## 三、银河麒麟（arm64 / x86_64）

1. 把对应的 `.deb` 拷到电脑上，在文件所在目录打开终端，运行（会要求输入当前用户的密码）：

   ```bash
   sudo dpkg -i P2D-<版本>-linux-arm64.deb
   ```

   也可以双击 `.deb` 用「麒麟软件安装器」安装。
2. 双击桌面上的「p2d」图标打开（开始菜单里也有；也可以运行 `/opt/p2d/p2d-desktop`）。安装时会给电脑上每个用户的桌面都放上图标。
3. 用数据线连接手机，后续和 Windows 相同。电脑端自己通过 USB 和手机通信，不需要 adb，不需要联网、不需要另外装软件。
4. 登录时要用默认的 X11 桌面（麒麟默认就是），截图和键鼠才能用。

### 麒麟安全中心的拦截

- **弹出「是否允许运行」**：执行控制是「警告」模式时，第一次运行会询问，点「允许」。
- **安装失败或程序打不开，提示未授权 / 未签名**：执行控制是「严格」模式，只允许运行有麒麟签名的程序。由管理员在「安全中心 → 应用保护」里把应用执行控制改为「警告」，或在终端运行：

  ```bash
  sudo setstatus -f exectl warning
  ```

  然后重新安装。查看当前模式：`getstatus`（看 `exec control` 一行）。
- **插上手机没有反应**：检查「安全中心 → 设备安全」里是否禁用了 USB 设备 / 手机。
- **WiFi 连接**（可选）：麒麟防火墙默认挡住手机通过 WiFi 连接。电脑端窗口「WiFi 直连」显示「被防火墙拦截」时，点「放行」并输入密码即可。只用数据线可以不管。

### 免调试连接（不开 USB 调试）

麒麟电脑上，手机可以不开「USB 调试」，直接用数据线连接（Android 配件模式，AOA）：

1. 手机上先装好 App（从发布页下载 `P2D-<版本>-android.apk` 安装；免调试连接时电脑没法给手机装 App）。
2. 插上数据线，电脑端窗口会列出这台手机，标着「未开 USB 调试」，点「免调试连接」。
3. 手机上弹出「用 P2D 打开」时点「确定」（勾上「默认情况下用于此 USB 配件」，以后不再询问），App 自动连上电脑。
4. 电脑端记住这台手机，以后插上就自动连接，不用再点。

说明：

- 连着时手机处于「配件模式」，这期间不能用数据线传文件（MTP），拔掉数据线就恢复。
- 手机开着 USB 调试时，仍然走 USB 调试连接（能自动装 App、更新 App），龙芯版也一样。
- 电脑端以普通用户身份访问手机的 USB 设备，靠 deb 安装包放的 udev 规则（`/lib/udev/rules.d/70-p2d.rules`）授权。用 `.tar.gz` 解压运行的，窗口会提示「没有权限访问这台手机的 USB 设备」，改用 deb 安装即可。
- 点了「免调试连接」手机却没反应：先解锁手机屏幕再点一次；仍不行可能是这款手机不支持配件模式，请开 USB 调试连接。
- Windows 不支持免调试连接：手机没开 USB 调试时，Windows 的 MTP 驱动占着手机，电脑发不出切换请求（要替换手机驱动才行，会影响传文件）。Windows 上请开 USB 调试。

## 三之一、Mac

1. 打开 `.dmg`，把「P2D」拖进「应用程序」。不知道是哪种芯片：左上角苹果菜单 →「关于本机」，写着 Apple M1 / M2 … 的用 arm64 版，写着 Intel 的用 x64 版。
2. 第一次打开：P2D 没有苹果的开发者签名，直接双击会提示「无法验证开发者」。
   - 在「应用程序」里右键（或按住 Control 点）P2D →「打开」→「打开」；
   - macOS 15 及以后：先双击一次，然后到「系统设置 → 隐私与安全性」，在最下面点「仍要打开」；
   - 如果提示「已损坏，无法打开」，在「终端」里运行 `xattr -cr /Applications/P2D.app` 后再打开。
3. 打开后窗口上会提示授权两项权限，点「去允许」，在系统设置里打开 P2D 的开关，然后退出 P2D 再重新打开：
   - **辅助功能**：手机控制鼠标、键盘；
   - **屏幕录制**：截图、远程桌面看画面。
4. 安卓手机：开好 USB 调试后用数据线插到 Mac 上即可，和 Windows 一样会自动装 App 并连接（Mac 不需要装驱动）。
5. 第一次有手机通过 WiFi 连接时，Mac 的防火墙（如果开着）会询问是否允许 P2D 接受连接，点「允许」。
6. Mac 上暂不支持读取界面控件（Agent 按截图操作），也不支持免调试连接（安卓手机要开 USB 调试）。

## 三之二、iPhone

iPhone 上的 App 不能由电脑自动安装，要先自己装好：

1. 安装 App：
   - 目前没有上架 App Store / TestFlight，发布页提供未签名的 `P2D-<版本>-ios-unsigned.ipa`，可以用 Sideloadly、AltStore 等工具用自己的 Apple ID 签名后装到 iPhone 上（免费 Apple ID 签名的 App 7 天后要重新签名）。
   - 第一次打开前，到「设置 → 通用 → VPN 与设备管理」里信任自己的 Apple ID；iOS 16 起还要在「设置 → 隐私与安全性 → 开发者模式」里打开开发者模式。
2. 数据线连接（iOS 没有 adb，经苹果的 usbmuxd 服务连接）：
   - **Mac**：系统自带，直接插线。
   - **Windows**：先从 Microsoft Store 安装「Apple 设备」（Windows 7 / 8 安装 iTunes），装好后再插线。
   - **银河麒麟**：先安装 usbmuxd（`sudo apt install usbmuxd`，离线环境用对应 CPU 的 deb 包），再插线。
   - 插上后 iPhone 上弹出「要信任此电脑吗？」点「信任」，然后打开 P2D App，保持在前台，几秒内自动连上。电脑端窗口显示「正在连接 iPhone」时，按窗口上的提示操作。
3. WiFi 连接：和安卓一样，在电脑端窗口点「配对新手机」，用 App 扫码配对，之后同一 WiFi 下不插线也能连。
4. iOS 的限制：App 切到后台不久就会被系统暂停，和电脑的连接随之断开，回到 App 后自动重连。让电脑执行较长的任务时，请保持 P2D 在前台。

## 四、使用

- **开机自启**：第一次运行后默认开启，开机后电脑端在后台运行（只在任务栏托盘显示图标），手机插上就能连。可以在窗口底部或托盘图标的右键菜单里勾选 / 取消「开机自启」。换了安装位置后，运行一次就会更新登记。

- **打开 App 时选电脑**：连过电脑后，每次打开 App 会先显示「选择电脑」页，列出记住的电脑、地址和现在能不能连上，点一台就连；右上角「跳过」直接进入。默认开着「自动连接」，会自动连上次用的电脑（插着数据线用 USB，否则用 WiFi），连上后自动进入；可以在手机「设置」里关掉。
- 连上后，手机上「虚拟桌面」可以实时看到并操作电脑屏幕，也可以让 Agent（需要在手机「设置 → 模型」里填写大模型的 API Key）代为操作。
  - 画面按电脑屏幕的原分辨率传，只传有变化的部分：打字、滚动时很流畅，文字清楚；整屏都在变（看视频、动态壁纸）时帧率会低一些。电脑端是旧版时退回以前的方式（画面缩到 1280 宽）。
  - 画面上是触控操作（和向日葵、UU 远程的触摸模式一样），手指点哪里鼠标就到哪里：
    - 轻点 = 点击，点两下 = 双击；
    - 单指滑动 = 滚动（聊天记录、网页、文档跟着手指走，快速一划有惯性）；
    - 长按（手机振动一下、出现圆圈）后拖动 = 按住左键拖动（选文字、拖窗口、拖文件）；长按后直接松手 = 右键；
    - 双指捏合 = 放大画面，放大后双指拖动平移画面（右上角点「还原」恢复）；双指轻点 = 右键。
  - 习惯用鼠标的可以打开「触控板」：滑动移动鼠标、轻点左键、长按右键、双指滑动滚动。
  - **黑屏**：虚拟桌面工具栏里点「黑屏」，电脑的显示器变黑（中间有一行灰色小字说明正在被远程控制），旁边的人看不到在操作什么，手机上照常看得到画面、照常操作。手机断开连接后电脑自动恢复显示，电脑旁边的人也可以按 Ctrl+Alt+Q 断开。选择会按电脑记住，以后连上这台电脑自动黑屏。需要 Windows 10 2004 及以上（Win7、麒麟、Mac 暂不支持）。
    - 黑屏期间电脑上弹出的右键菜单等置顶窗口可能会短暂露出来，不到半秒又会被盖住。
- 电脑屏幕四周出现红框表示正在被手机控制。随时可以在电脑端窗口点「断开」，或按窗口里显示的热键（默认 `Ctrl+Alt+Q`）断开。
- 拔掉数据线即断开；再插上会自动重连。
- **同时操作多台电脑**：手机「设备」页里，点其他电脑右边的「⋯」→「同时连接」，就能再连几台配对过的电脑（走 WiFi 或 Tailscale；数据线一次只能插一台）。之后在同一个对话里告诉 Agent 在哪台做，或者「两台都…」，它会分别操作，不同电脑上的操作同时进行；也能用「把 A 上的某个文件传到 B」在电脑之间传文件（保存到 B 的「下载/P2D」，需要两台电脑端都是新版）。虚拟桌面右上角可以切换看哪台，Agent 操作哪台就自动切到哪台。开着「自动连接」时，下次打开 App 会自动重新连上这些电脑。
- **定时任务指定电脑**：手机「定时任务」里新建或编辑任务时，可以选在哪几台电脑上执行（不选就是到时连着的当前电脑），也可以直接跟 Agent 说「每天早上 8 点给办公室和家里的电脑体检」。到点后会自动连上选中的电脑（走 WiFi 或 Tailscale，电脑需要配对过），执行完断开临时连接；2 分钟内没连上的电脑这次跳过，结果里会说明。手机 App 需要开着（或点到点通知打开）。
- **出了问题导出日志**：电脑端点窗口右下角「关于 → 导出日志」（窗口打不开时用托盘右键「导出日志…」），默认存到桌面；手机端在「设置 → 关于 → 导出日志」，可以分享到微信 / QQ，或连着电脑时直接存到电脑。日志不含对话内容、API Key、配对令牌。连同问题描述一起发到项目主页（「关于」里有 GitHub 链接）的 Issues。

## 五、更新到新版本

- **从 PhoneToDesktop 改名为 p2d**：直接装新版就行，不用先卸载旧版。
  - Windows：安装程序会关掉旧的 PhoneToDesktop.exe，在原来的位置换成新的程序（现在叫 P2D.exe）。
  - 麒麟：新的 deb 包叫 `p2d`，安装时会自动卸掉旧的 `phonetodesktop` 包，程序改装到 `/opt/p2d`。
  - 第一次打开新版时，配对记录和设置会自动从 `PhoneToDesktop` 目录搬到 `p2d` 目录（Windows 在 `%APPDATA%`，麒麟在 `~/.config`），开机自启也会改成新名字；已经放行过的麒麟防火墙规则继续有效。
  - 改名后传到电脑的文件存到「下载/P2D」，以前的文件还在「下载/PhoneToDesktop」。
- **名字改成大写的 P2D**：界面、安装包文件名、桌面图标都改成 P2D；程序目录、数据目录、deb 包名、手机 App 包名保持小写不变，直接覆盖安装即可。麒麟上原来的「下载/p2d」文件夹会在第一次收文件时改名为「下载/P2D」。
  - 手机 App 新旧版都能和新版电脑端免调试连接。

- **新版电脑端不再带 adb**：开了 USB 调试的手机由电脑端自己连接，和以前的用法一样。以前在这台电脑上点过「允许 USB 调试」（并勾选「一律允许」）的手机不用再点一次；没勾选过的手机第一次连接时会再弹一次。

- **能上网的电脑**：电脑端会自动检查更新，有新版本时窗口顶部提示，点「下载新版本」用浏览器下载；也可以点窗口右下角「关于 → 检查」或托盘右键菜单「检查更新」。
  - Windows：直接运行新下载的安装程序，它会关闭正在运行的旧版本、覆盖安装，配对记录和设置都保留。
  - 麒麟：双击新的 `.deb` 安装（或 `sudo dpkg -i 文件名`），直接覆盖旧版本，配对记录和设置都保留，装完重新打开。
- **不能上网的电脑**：在能上网的电脑上下载新版本的安装包，用 U 盘拷过去，按上面的方法覆盖安装。
- **手机**：用数据线连接已经更新的电脑时，电脑端会自动给手机更新 App，不用另外操作。只用 WiFi / Tailscale 连接的手机，可以在 App「设置 → 关于」里点「检查更新」下载新的 APK 安装。
- 0.1.0-ci.5 及更早的版本还没有检查更新功能，需要按上面「不能上网的电脑」的方法手动更新一次。

## 六、通过 Tailscale 远程连接（可选）

手机和电脑不在同一个 WiFi 时（比如在外面用手机流量），可以借助 Tailscale 组的虚拟局域网连接：

1. 电脑和手机都安装 Tailscale，并登录**同一个** Tailscale 账号（或同一个 Headscale 网络）。
2. 先按正常方式让手机和电脑配对一次：插一次数据线，或在同一个 WiFi 下扫码配对。
3. 之后手机只要连着 Tailscale，在任何网络下打开 App 都会自动连上电脑。也可以在手机「添加电脑 → 输入 IP」里填电脑端窗口「Tailscale 远程」一行显示的 100 开头的地址。

注意：

- 连接内容本身已经端到端加密，走 Tailscale 不降低安全性。
- Windows：第一次运行时防火墙会询问是否允许 `p2d-core` 联网，「专用网络」和「公用网络」都要勾选（Tailscale 的网卡可能被识别为公用网络）。已经点过的，可以在「控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙」里补勾。
- 麒麟：电脑端窗口「WiFi 直连」显示「被防火墙拦截」时点「放行」，Tailscale 连接同样需要。
- 生产环境不能上网的电脑用不了 Tailscale（它需要连接 Tailscale 的服务器或自建的 Headscale）。

## 七、已知限制

- 电脑上开着 Android Studio 等程序自己的 adb 时，手机被它占着，电脑端会经它连接，用法不变。被别的程序（如手机助手类软件）占着时，电脑端窗口会提示「手机的 USB 调试接口被其他程序占用」，关掉那个程序再插拔数据线。
- 免调试连接只支持银河麒麟（Linux），Windows 和 Mac 上需要开 USB 调试。
- 不支持：龙芯 3A4000（mips64el）、申威（sw64）。
- Mac 版、iPhone 版目前只在 GitHub 的 macOS 机器上编译通过，还没有在真机上测试过；Mac 版和 iPhone 版都没有苹果开发者签名。
- iPhone 不能由电脑自动安装、更新 App，切到后台会断开（见「iPhone」一节）。
- 手机 App 用正式证书签名。手机上如果装过测试版，需要先卸载，电脑端才能自动装上新版。
