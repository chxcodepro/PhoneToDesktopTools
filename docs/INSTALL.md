# PhoneToDesktop 安装说明

用手机通过数据线控制电脑。电脑端支持 Windows 10 / 11、Windows 7 SP1、银河麒麟桌面操作系统 V10（SP1）。不需要联网。

## 交付文件

| 文件 | 用途 |
|---|---|
| `PhoneToDesktop-<版本>-android.apk` | 手机端 App（一般不用手动装：手机插上电脑时，电脑端会自动安装） |
| `PhoneToDesktop-<版本>-win-x64-portable.exe` | Windows 10 / 11 / 7 的 64 位电脑 |
| `PhoneToDesktop-<版本>-win-ia32-portable.exe` | 32 位 Windows（少见，64 位系统用上面那个） |
| `PhoneToDesktop-<版本>-linux-arm64.deb` | 银河麒麟 arm64（飞腾、鲲鹏、海思麒麟） |
| `PhoneToDesktop-<版本>-linux-amd64.deb` | 银河麒麟 x86_64（兆芯、海光、Intel） |
| `PhoneToDesktop-<版本>-linux-loongarch64.deb` | 银河麒麟龙芯 3A5000 / 3A6000（只能用 WiFi 连接，见文末） |

不确定麒麟电脑是哪种 CPU：打开终端运行 `uname -m`，`aarch64` 用 arm64 版，`x86_64` 用 amd64 版，`loongarch64` 用龙芯版。

## 一、手机准备（每台手机做一次）

1. 打开「开发者选项」：设置 → 关于手机 → 连续点「版本号」7 次。
2. 设置 → 系统（或「其他设置」）→ 开发者选项，打开「USB 调试」。
   - 小米手机还要打开「USB 安装」和「USB 调试（安全设置）」。
   - OPPO / 一加 / vivo 如有「禁止权限监控」「USB 安装需验证」之类的选项，按提示允许。
3. 第一次插上电脑时，手机会弹出「允许 USB 调试吗？」，勾选「一律允许这台计算机」，点「允许」。

## 二、Windows 10 / 7

1. 把 `PhoneToDesktop-<版本>-win-x64-portable.exe` 拷到电脑上一个固定的位置（比如 `C:\PhoneToDesktop\`），双击运行。是便携版，不用安装；每次启动要解压几秒。**不要直接从 U 盘运行**：开机自启登记的是 exe 所在的位置，拔了 U 盘开机就找不到了。
2. 用数据线连接手机。电脑端会自动给手机安装 App 并连接，窗口显示「已连接 · USB」即可在手机上操作电脑。
3. 如果窗口里「Android 驱动」显示「缺少驱动」（Win7 常见）：点「安装驱动」→ 弹出的管理员确认点「是」→ 提示「无法验证此驱动程序软件的发布者」时点「始终安装此驱动程序软件」。装好后自动连接。
4. Win7 需要 SP1。电脑端自带了 adb 需要的运行库，没打系统补丁的 Win7 也能用。

## 三、银河麒麟（arm64 / x86_64）

1. 把对应的 `.deb` 拷到电脑上，在文件所在目录打开终端，运行（会要求输入当前用户的密码）：

   ```bash
   sudo dpkg -i PhoneToDesktop-<版本>-linux-arm64.deb
   ```

   也可以双击 `.deb` 用「麒麟软件安装器」安装。
2. 双击桌面上的「PhoneToDesktop」图标打开（开始菜单里也有；也可以运行 `/opt/PhoneToDesktop/p2d-desktop`）。安装时会给电脑上每个用户的桌面都放上图标。
3. 用数据线连接手机，后续和 Windows 相同。安装包里自带了 adb，不需要联网、不需要另外装软件。
4. 登录时要用默认的 X11 桌面（麒麟默认就是），截图和键鼠才能用。

### 麒麟安全中心的拦截

- **弹出「是否允许运行」**：执行控制是「警告」模式时，第一次运行会询问，点「允许」。
- **安装失败或程序打不开，提示未授权 / 未签名**：执行控制是「严格」模式，只允许运行有麒麟签名的程序。由管理员在「安全中心 → 应用保护」里把应用执行控制改为「警告」，或在终端运行：

  ```bash
  sudo setstatus -f exectl warning
  ```

  然后重新安装。查看当前模式：`getstatus`（看 `exec control` 一行）。
- **插上手机没有反应**：检查「安全中心 → 设备安全」里是否禁用了 USB 设备 / 手机。
- **WiFi 连接**（可选）：麒麟防火墙默认挡住手机通过 WiFi 连接。电脑端窗口「WiFi 直连」显示「被防火墙拦截」时，点「放行」并输入密码即可。只用数据线可以不管。

## 四、使用

- **开机自启**：第一次运行后默认开启，开机后电脑端在后台运行（只在任务栏托盘显示图标），手机插上就能连。可以在窗口底部或托盘图标的右键菜单里勾选 / 取消「开机自启」。Windows 便携版换了位置后，从新位置运行一次就会更新登记。

- 连上后，手机上「虚拟桌面」可以实时看到并操作电脑屏幕，也可以让 Agent（需要在手机「设置 → 模型」里填写大模型的 API Key）代为操作。
- 电脑屏幕四周出现红框表示正在被手机控制。随时可以在电脑端窗口点「断开」，或按窗口里显示的热键（默认 `Ctrl+Alt+Q`）断开。
- 拔掉数据线即断开；再插上会自动重连。

## 五、更新到新版本

- **能上网的电脑**：电脑端会自动检查更新，有新版本时窗口顶部提示，点「下载新版本」用浏览器下载；也可以点窗口右下角「检查更新」或托盘右键菜单「检查更新」。
  - Windows：托盘图标右键「退出」，运行新下载的 exe（放到原来的位置，可以删掉旧的）。开机自启会自动改成新 exe。
  - 麒麟：双击新的 `.deb` 安装（或 `sudo dpkg -i 文件名`），直接覆盖旧版本，配对记录和设置都保留，装完重新打开。
- **不能上网的电脑**：在能上网的电脑上下载新版本的安装包，用 U 盘拷过去，按上面的方法覆盖安装。
- **手机**：用数据线连接已经更新的电脑时，电脑端会自动给手机更新 App，不用另外操作。只用 WiFi / Tailscale 连接的手机，可以在 App「设置 → 关于」里点「检查更新」下载新的 APK 安装。
- 0.1.0-ci.5 及更早的版本还没有检查更新功能，需要按上面「不能上网的电脑」的方法手动更新一次。

## 六、通过 Tailscale 远程连接（可选）

手机和电脑不在同一个 WiFi 时（比如在外面用手机流量），可以借助 Tailscale 组的虚拟局域网连接：

1. 电脑和手机都安装 Tailscale，并登录**同一个** Tailscale 账号（或同一个 Headscale 网络）。
2. 先按正常方式让手机和电脑配对一次：插一次数据线，或在同一个 WiFi 下扫码配对。
3. 之后手机只要连着 Tailscale，在任何网络下打开 App 都会自动连上电脑。也可以在手机「添加电脑 → 输入 IP」里填电脑端窗口「Tailscale 远程」一行显示的 100 开头的地址。

注意：

- 连接内容本身已经端到端加密，走 Tailscale 不降低安全性。
- Windows：第一次运行时防火墙会询问是否允许 `p2d-core` 联网，「专用网络」和「公用网络」都要勾选（Tailscale 的网卡可能被识别为公用网络）。已经点过的，可以在「控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙」里补勾。
- 麒麟：电脑端窗口「WiFi 直连」显示「被防火墙拦截」时点「放行」，Tailscale 连接同样需要。
- 生产环境不能上网的电脑用不了 Tailscale（它需要连接 Tailscale 的服务器或自建的 Headscale）。

## 七、已知限制

- 龙芯版（3A5000 / 3A6000）：目前没有可用的 adb，只能用 WiFi 连接（手机端 App 需要手动安装 APK，然后在电脑端窗口点「配对新手机」扫码）。
- 不支持：龙芯 3A4000（mips64el）、申威（sw64）、iPhone。
- 手机 App 用正式证书签名。手机上如果装过测试版，需要先卸载，电脑端才能自动装上新版。
